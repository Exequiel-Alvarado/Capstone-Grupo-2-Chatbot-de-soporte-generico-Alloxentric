# entregables/

Estructura oficial de entregables de **APT122**, tomada de la pauta de la escuela
(`recursos/documentos/info.pdf`). Los archivos se suben **manualmente** aquí, ya con el
nombre exacto que exige la pauta.

> El nombre de archivo se evalúa. Copiar y pegar de las tablas de abajo, no escribirlo de
> memoria.

## Alcance de este repositorio

Este repo guarda **los entregables académicos**. El código, la arquitectura viva, los ADR y
el backlog técnico están en el repositorio privado del proyecto — ver
`recursos/avances/TRASPASO.md`.

Lo único que cruza desde el privado hacia acá son las **evidencias de sistema** de la Fase 2
(capturas de la aplicación, esquema de base de datos, documentación), al cierre de la fase.

## Cómo se llena

1. Se trabaja el borrador en `recursos/avances/fase-N/` (local, fuera de git).
2. Cuando está listo, se copia acá con el nombre oficial —
   `python scripts/promover.py` lo hace para la Fase 1.
3. Commit + push, y se sube la misma versión a Drive.
4. Se marca ✅ en la tabla que corresponda y en `recursos/avances/bitacora.md`.
